メール翻訳とストレージの管理

1. Gemini API キー設定

Google AI Studio で取得した API キーを入力してください。API キーは Web Crypto API (AES-GCM 256bit) により暗号化され、安全にローカル保存されます。

確認中...
Thunderbird 起動後の初回翻訳時にこの PIN の入力が求められます。

2. 使用モデル選択

翻訳に使用する Gemini モデルを選択します。API キーを保存すると自動で最新の利用可能モデル一覧を取得します。

API 通信タイムアウト設定 (ストリーミング対応)

ストリーミング API (:streamGenerateContent) による翻訳通信のタイムアウト時間（秒）を指定します。

秒
最初の応答またはチャンク受信間隔がこれを超えるとタイムアウトします (デフォルト: 30 秒、範囲: 5〜300)。
秒
翻訳リクエスト開始から完了までの最大許容時間を指定します (デフォルト: 90 秒、範囲: 10〜600)。

3. 翻訳プロンプト設定

Gemini に送信する翻訳プロンプト（指示文）を5種類から選択・編集できます。

4. LLM パラメータ設定

翻訳生成時の多様性（温度・Top-K・Top-P・乱数シード）およびセーフティフィルタの厳しさを設定します。

0.5
値が高いほど創造的で多様な表現になり、低いほど一貫した正確な翻訳になります (デフォルト: 0.5、範囲: 0〜2)。 ※ 現在選択中のモデルは温度（temperature）の設定に対応していないため無効化されています。
各生成ステップで候補とする単語の最大数を指定します (デフォルト: 7、範囲: 1〜40)。 ※ 現在選択中のモデルは Top-K の設定に対応していないため無効化されています。
0.90
累積確率がこの値に達するまでの単語群から選択します (デフォルト: 0.90、範囲: 0.01〜1.00)。 ※ 現在選択中のモデルは Top-P の設定に対応していないため無効化されています。
固定値を指定すると、同じ入力テキストに対して決定論的な同一結果が得られやすくなります (範囲: 0〜2147483647)。 ※ 現在選択中のモデルは乱数シード（seed）の設定に対応していないため無効化されています。
対応モデル（Gemini 3 / 4 系など）における内部推論（思考）の深さを指定します。通常はデフォルトまたは低・中で高速に翻訳できます。 ※ 現在選択中のモデルは思考レベル（thinkingLevel）の設定に対応していないため無効化されています。
Tokens
モデルが1回の応答で出力する最大トークン数を指定します (デフォルト: 5000 Tokens、範囲: 100〜65536)。 ※ 現在選択中のモデルは最大出力トークン数の設定に対応していないため無効化されています。
byte
過大データによるメモリ枯渇を防ぐため、前処理およびAPI送信時に許容するメール本文の最大サイズを指定します (デフォルト: 50000 byte、範囲: 1000〜500000)。

セーフティ設定 (Safety Settings)

不適切な表現や有害コンテンツに対するGeminiのフィルタリング強度を指定します (デフォルト: すべて高のみブロック)。

    5. ショートカットキー設定

    メール本文のテキスト選択中に押すことで、素早く選択テキストを翻訳するショートカットキーを設定します。

    Alt +
    アルファベットまたは数字を1文字指定してください（デフォルト: t）。
    Alt +
    アルファベットまたは数字を1文字指定してください（デフォルト: m）。
