メール翻訳とストレージの管理

1. Gemini API キー設定

Google AI Studio で取得した API キーを入力してください。API キーは Web Crypto API (AES-GCM 256bit) により暗号化され、安全にローカル保存されます。

確認中...
Thunderbird 起動後の初回翻訳時にこの PIN の入力が求められます。

2. 使用モデル選択

翻訳に使用する Gemini モデルを選択します。API キーを保存すると自動で最新の利用可能モデル一覧を取得します。

3. 翻訳プロンプト設定

Gemini に送信する翻訳プロンプト（指示文）を5種類から選択・編集できます。

4. LLM パラメータ設定

翻訳生成時の多様性（温度・Top-K・Top-P・乱数シード）およびセーフティフィルタの厳しさを設定します。

0.5
値が高いほど創造的で多様な表現になり、低いほど一貫した正確な翻訳になります (デフォルト: 0.5、範囲: 0〜2)。
各生成ステップで候補とする単語の最大数を指定します (デフォルト: 7、範囲: 1〜40)。
0.90
累積確率がこの値に達するまでの単語群から選択します (デフォルト: 0.90、範囲: 0.01〜1.00)。
固定値を指定すると、同じ入力テキストに対して決定論的な同一結果が得られやすくなります (範囲: 0〜4294967295)。
Tokens
モデルが1回の応答で出力する最大トークン数を指定します (デフォルト: 5000 Tokens、範囲: 100〜65536)。
byte
過大データによるメモリ枯渇を防ぐため、前処理およびAPI送信時に許容するメール本文の最大サイズを指定します (デフォルト: 50000 byte、範囲: 1000〜500000)。

セーフティ設定 (Safety Settings)

不適切な表現や有害コンテンツに対するGeminiのフィルタリング強度を指定します (デフォルト: すべて高のみブロック)。

5. ショートカットキー設定

メール本文のテキスト選択中に押すことで、素早く選択テキストを翻訳するショートカットキーを設定します。

Alt +
アルファベットまたは数字を1文字指定してください（デフォルト: t）。
Alt +
アルファベットまたは数字を1文字指定してください（デフォルト: m）。

6. 保存された翻訳データ・メモの管理

ローカルストレージ (browser.storage.local) に保存されたメール翻訳データ・メモの整理、最大保持件数の自動管理、および削除を行います。
